# Tale Fairy

Tale Fairy is a SillyTavern extension that acts as a background creative Game Master for roleplay. It uses the RP's premise, setting, characters, and accepted history to keep a private working plan and offer the writer relevant story opportunities. It supports original worlds and franchise settings, including changes made during play.

## Goals

- Make opportunities fit the RP: everyday life, relationships, travel, discoveries, conflict, or quiet moments when appropriate, not a generic quest loop.
- Keep meaningful past events and plausible NPC or world activity in view without forcing old threads to continue forever.
- Offer possibilities, not scripted scenes or predetermined outcomes. Player choices remain open; the user's writing preset controls prose, tone, and pacing.
- Stay lightweight and optional. Tale Fairy is not a historical memory system and does not write story replies on its own.

## Install

In SillyTavern, install `https://github.com/scatteredlilies2020/Tale-Fairy` from **Extensions > Install Extension**, then reload SillyTavern.
