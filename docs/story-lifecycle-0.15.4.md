## Changes

- Separate scene freshness from the explicitly selected outlook. Expired local
  circumstances are omitted, while matching, accessible mid- and long-term
  possibilities remain available from an exact accepted source prefix. This is
  a read-only projection, not a rewrite or promotion of private trajectories.
- Successful automatic reviews start one accepted assistant reply before the
  scene-material lifetime ends (minimum one reply). Stop retains its normal
  cadence; failure recovery still requires new accepted play or a manual request.
- A substantive same-source memory update can cause one rebase, rebuilding both
  stages from fresh evidence. It must fit the original three-request ceiling;
  corrections and rebase calls share that budget. Drafts never commit separately.
- Publication counters alone no longer invalidate identical evidence. Content,
  coverage, status and authority remain part of its identity. A stable registry
  module preserves public evidence registrations across versioned browser readers.
- Chat edits, changed references/settings, a newer run, changed saved preparation,
  disabling, and Stop still prevent an unsafe commit or rebase. Diagnostics name
  the changed source category instead of collapsing it into one generic error.
- Preview, regeneration, cached-packet authentication and normal generation use
  the same scoped writer material. Browser import cache markers cover all affected
  modules and their transitive importers.

No new planner stage, generated story reply, franchise-specific rule or injected
writing instruction was added. The writer context retains the existing hard cap.

late updates with insufficient budget, unchanged republishing, every source/Stop
guard, earlier event cadence, horizon-only preview/reload/regeneration, cache

An offline replay of the actual 27-message saved source validates revision 4 and
retains its conditional hearing/border possibilities while omitting the expired

Provider outages, malformed model responses and continuous source changes can
still prevent a refresh. When the bounded recovery cannot safely finish, the last
saved preparation remains intact, stale local material stays withheld, and the
failure is reported. This fixes lifecycle loss, not every possible model-quality
failure or the writer's choice of how to use a future possibility.
